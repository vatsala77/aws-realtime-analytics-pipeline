 
# AWS Realtime Analytics Pipeline

Real-time log analytics + anomaly detection pipeline that ingests live traffic 
from [Rate Limiter Project](LINK_HERE) using Kinesis Firehose, processes it via 
Lambda, catalogs it with Glue, queries with Athena, and surfaces anomalies via 
SNS alerts — visualized on a React dashboard.
